# Evidence-Based Technical Analysis

David R. Aronson's book applies statistical inference and the scientific method to evaluating trading rules, with special attention to rules discovered through data mining. Wiley lists a 2006 hardcover edition (ISBN 9780470008744) and a 2011 digital edition. [Publisher record](https://uat.store.wiley.com/en-us/evidence-based-technical-analysis-applying-the-scientific-method-and-statistical-inference-to-trading-signals-p-9781118268315)

**Why it is first for PulseQuant:** the 62% win rate is currently a UI assumption, while the source document explicitly says it has no backtest establishing an edge. This is the most directly relevant of the four for turning “the signal looks good” into a falsifiable test that accounts for searching many variants.

**Apply it to:** define the signal and barriers before testing; record every tried variant; separate development from validation; estimate uncertainty; report net results after costs. Do not treat one favorable historical backtest as proof of future performance.

The statistical ideas remain useful, but this is an older text. Pair it with current data-leakage and walk-forward practices. It teaches evaluation; it does not supply a profitable signal.
